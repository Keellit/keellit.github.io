KeellitDev — готовый сайт для GitHub Pages
========================================

СОДЕРЖИМОЕ
index.html — главная страница сайта
styles.css — стили (адаптивная верстка)
assets/ — логотип и изображения Numera

КАК ОПУБЛИКОВАТЬ
1. Войди в GitHub под пользователем Keellit.
2. Создай публичный репозиторий с точным названием keellit.github.io:
   https://github.com/new
3. Распакуй этот ZIP-архив.
4. В репозитории нажми «Add file» → «Upload files».
   Перетащи содержимое распакованной папки в репозиторий:
   index.html, styles.css и папку assets со всеми файлами.
   Важно: index.html должен быть в корне репозитория.
5. Нажми «Commit changes».
6. Перейди Settings → Pages → Build and deployment.
   Source: Deploy from a branch
   Branch: main / (root)
   Сохрани настройки.
7. После успешной публикации сайт откроется по адресу:
   https://keellit.github.io/
8. Открой Unity Publisher Portal → Profile → Website
   и укажи https://keellit.github.io/

ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ
- Статический сайт: HTML + CSS, не требует сервера и сборки.
- Адаптивен под ПК и телефоны.
- Изображения оптимизированы в WebP; Google Fonts могут не загрузиться
  при отсутствии интернета, но используются системные шрифты как запасные.
- Для изменения информации правь index.html, для оформления styles.css.
- Изображения для презентации Numera были предоставлены владельцем проекта.
